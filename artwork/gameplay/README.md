# Gameplay screenshots

These six development captures are published with the game owner's permission from the website task on 2 November 2026.

Five images are frames from the native Unity gameplay trailer, including its original English captions. The alliance image was recaptured in Unity on 6 November 2026 using the game's English localization and sample teams and scores. No gameplay imagery was generated or retouched for the website.

`provenance.json` records the project-relative sources, video timestamps, source SHA-256 hashes and hashes of both proportional WebP sizes. The 480-pixel files serve the selector thumbnails; 1600-pixel files serve the selected image and full screenshot link. The source PNG for the alliance capture remains in the game workspace.

Game facts were checked against `Docs/LiveRounds_2026-09-26.md`, `Docs/LiveArenaSpectators_2026-10-09.md` and the alliance event client services in the game project. The planned December 2026 Android release was confirmed by the owner in this session; it is a target, not a fixed launch date.
